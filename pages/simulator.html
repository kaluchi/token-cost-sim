Длительный vs Объёмный контекст

Почему «объёмный» контекст (много данных, мало итераций) дешевле «длительного» (мало данных, много итераций)

⚡

Два вида нагрузки на контекст

Длительный контекст — много мелких итераций, постепенное накопление: 60 вызовов с мелкими tool results. Итог: квадратичная переплата за перечитывание. Объёмный контекст — мало итераций, но крупный начальный контекст: документация, спецификации, релевантный код загружены сразу. Финальный контекст может быть больше — но счёт ниже, потому что квадрат числа итераций доминирует над линейным размером контекста.

Интерпретация результатов

Откуда берётся «квадратичная кухня»

При каждом API-вызове модель обрабатывает весь накопленный контекст. При N вызовах и δ токенах/вызов:

Σ input_k ≈ C₀·N + δ·N·(N−1)/2 ≈ δ·N²/2 (квадратично по N)
Роль Prompt Caching
С кэшем: cost_k ≈ C_{k-1} · P_cache_read + Δk · P_input + r_k · P_output ↳ квадратичный коэффициент уменьшается в 10× (P_cache_read ≈ 0.1 · P_input)
Гранулярность tool results
cost ≈ δ·N²/2 = (X/N)·N²/2 = X·N/2 → меньше N = дешевле при том же финальном контексте
Thinking-токены (Extended Thinking)

Thinking-токены биллятся как output при генерации и накапливаются в контексте как input в следующих вызовах. Слайдер «Model output / вызов» должен включать оба компонента:

Model output / вызов = thinking-токены + видимый ответ Пример (Opus 4 extended thinking): 8 000 thinking + 2 000 ответ = 10 000 total → биллинг: 10 000 × P_output за генерацию → следующий вызов: эти 10 000 читаются из кэша по P_cache_read (~10% цены)

Это значит: у моделей с большим thinking-окном квадратичный эффект усиливается — thinking-хвост давит на кэш каждого следующего вызова.

Практические рекомендации
  • Загружайте документацию один раз — с кэшем каждый последующий вызов читает её за ~10% цены
  • Инструменты, возвращающие крупные блоки за один вызов, дешевле многих мелких
  • Хороший промт снимает неоднозначность до старта — прямая экономия на итерациях
  • N×2 итерации дороже, чем N итераций с 2× бо́льшим контекстом
  • Extended Thinking: thinking-токены включай в слайдер «Model output» — без этого симулятор недооценит стоимость
